# 节日航班服务包编排

面向节日主题航班“临时换机型”等扰动场景的空地一体服务包编排服务。值班经理需要当场回答的问题——**原定广播、点心、手作物料、非遗体验中哪些照常、哪些必须换、剩余风险谁承担**——由系统依据运行日期、起飞机场、航线、舱位与休息室条件裁决出“现场可执行版本”，并对内容审定、供应批次、过敏原声明、配额、替代依据、签收责任全部留痕。

只使用 Node.js 内置能力，运行期间不连接其他服务。

## 核心裁决原则

- **生效日按计划起飞地当地日期。** 跨午夜航班以起飞机场时区的当日规则为准（`src/dates.js`），例如 UTC 10-01 16:05 从北京起飞，当地已是 10-02，按 10-02 批件/批次窗口裁决。
- **现场可执行版本由五条件共同决定：** 运行日期、起飞机场、航线、舱位（机上）/休息室（地面）、当前机型。
- **爆炸半径隔离：**
  - 某城市缺货只悬置“发货地=该城市”的实物条目，不连带撤回其他城市已确认安全的物料；
  - 食品批次停用只击中该批次承载的实物条目，**广播等内容没有批次概念，绝不被波及**；
  - 换机型只让“机型专属”条目出范围，其余照常。
- **替代品必须重新核对适用范围：** 替代品携带自己的内容/物料审定批件、供应批次、过敏原声明并重新过闸，不得沿用原批准；批准编号与原批件相同将被直接拒绝。替代关系按**每个清单（现场）隔离**，在商务舱通过的替代不会替经济舱“消悬置”。
- **重复消息只处理一次：** 装载、签收事件以 `eventId` 幂等。
- **内容冲突交独立岗位：** 同一装机任务出现数量/状况冲突的上报时挂起，开“冲突核对单”，由非上报人的独立岗位裁决；冲突未决不得签收。
- **责任随签收交接：** 悬置期风险归供应方/地面保障方（批次停用→批次责任方，城市缺货→该城市地面保障方），审定不合格归批件责任方，出范围归编排岗；条目签收后责任移交客舱乘务组（机上）或休息室值班岗（地面），交接链逐环留痕。
- **故障恢复续派：** 恢复后只继续派发仍未完成的任务，已签收不重复。
- **时点视图不被覆盖：** 所有清单/单据只追加修订。事后查看某班航班或某间休息室，得到的是当时应备、实际签收、替代理由与责任交接，而非被后续修改覆盖的当前模板。

## 条目现场状态

| 状态 | 含义 |
|---|---|
| `active` | 全部闸门通过，照常提供，产生装载/签收任务 |
| `suspended` | 供应事件定点悬置（批次停用/城市缺货），等待替代，风险在供应/地面方 |
| `replaced` | 已被在本现场生效的替代品顶替，原条目停止执行 |
| `not_approved` | 审定/批次/过敏原/配额任一闸门未过，不得装机 |
| `out_of_scope` | 不在当前日期/航线/舱位/机型/休息室（含机上↔地面）适用范围 |

## 模块

- `src/dates.js` — 时区偏移与“起飞地当地日期”工具（纯函数）。
- `src/rules.js` — 裁决内核：适用范围、内容审定、供应批次、过敏原、配额五闸门，状态与任务推导（纯函数）。
- `src/store.js` — 版本化文档（只追加修订、任一时点回看）、按 `eventId` 幂等的事件日志、任务与派发出厂记录。
- `src/service.js` — 编排应用服务：登记、建包、换机型重评、定点悬置、替代重审、幂等装载签收、独立冲突核对、责任交接、故障恢复、值班视图。
- `src/api.js` — 进程内 JSON 请求路由。
- `src/cli.js` — 标准输入入口。

## 主要动作（JSON `action`）

资料：`registerAirport` `registerLounge` `registerFlight` `changeAircraft`
`registerApproval` `registerBatch` `registerAllergenDeclaration` `setQuota`
`registerCatalogEntry` `registerPackage`

供应事件：`holdCityStock` `releaseCityStock` `stopBatch`

编排：`buildFlightManifest` `buildLoungeManifest` `refreshManifest` `proposeSubstitution`

现场执行：`reportLoad` `reportSignoff` `resolveLoadConflict` `recoverDispatch`

值班视图：`viewFlight` `viewLounge`（支持 `at` 指定回看时点）
